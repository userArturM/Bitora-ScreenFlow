# Bitora ScreenFlow — запись экрана

Приложение для Windows 10/11, 64 бит (x64). Интерфейс на русском языке.
Работает локально: записи не отправляются в интернет.

## Скачать и запустить

Готовые сборки: https://github.com/userArturM/bitora/releases/latest
Репозиторий приватный: для скачивания нужен доступ к нему.

**Установщик** — Bitora-ScreenFlow-Setup-1.3.2-x64.exe.
Запустите, выберите папку и завершите установку. Создаются ярлыки на рабочем
столе и в меню «Пуск». Удаление доступно через настройки приложений Windows.
Пользовательские записи при удалении сохраняются.

**Портативная версия** — Bitora-ScreenFlow-Portable-1.3.2-x64.exe.
Запускается без установки. Положите EXE в папку с правом записи. При первом
запуске рядом создаётся BitoraScreenFlow-Data с настройками и видео.
Для переноса на другой ПК копируйте EXE вместе с этой папкой.
Первый запуск может занять время: приложение распаковывается во временную папку.
Если выбрали отдельную папку видео, она остаётся внешней и автоматически не переносится.

Node.js, интернет и администраторские права для обычной работы не нужны.
Приложение не имеет цифровой подписи издателя.

Выберите источник → настройте звук → начните запись → завершите кнопкой
или Ctrl + Shift + R. Результат появится в «Мои записи».

## Возможности

- Выбор монитора или отдельного окна с миниатюрами.
- Запись системного звука, микрофона или их смеси; индикатор уровня звука во время записи.
- Выбор микрофона после включения доступа к нему.
- 15, 30 или 60 кадров в секунду; целевой видеобитрейт 4, 8 или 16 Мбит/с.
- Пауза и продолжение в одном видео.
- Отсчёт перед стартом и автоматическое сворачивание.
- Значок в области уведомлений: время записи в подсказке, меню «Пауза», «Завершить запись», «Показать окно».
- Горячие клавиши по умолчанию: Ctrl + Shift + R — начало / завершение, Ctrl + Shift + P — пауза.
  Сочетания меняются в «Дополнительно» (нужен Ctrl или Alt).
- Свободное место на диске и оценка, на сколько часов его хватит; предупреждение при остатке менее 2 ГБ
  и автоматическая остановка с сохранением при остатке менее 300 МБ.
- Автосохранение настроек и выбор папки записей.
- «Мои записи»: превью и длительность, открытие во внешнем плеере, показ в проводнике,
  сохранение копии, переименование, удаление в корзину.
- Сохранение в MP4 (H.264 + AAC) для плееров и сайтов без поддержки WebM.
- Исправление WebM без перекодирования: добавляются длительность и перемотка,
  незавершённые записи (.partial.webm) восстанавливаются. После каждой записи это
  происходит автоматически (можно отключить в «Дополнительно»).
- Запись блоками на диск, без накопления всего видео в оперативной памяти.
- Предотвращение сна во время записи; сохранение перед обычным закрытием приложения.

## Куда сохраняется видео

Установленная версия: пользовательская папка «Видео» → Bitora ScreenFlow.
Портативная версия: BitoraScreenFlow-Data/Recordings рядом с EXE.
Путь отображается в «Мои записи»; его можно изменить до начала записи.
Формат записи: WebM (VP9 либо VP8, звук Opus). Для плееров без WebM используйте
кнопку «Сохранить как MP4» в «Мои записи»: конвертация перекодирует видео, поэтому
занимает время, сравнимое с длительностью записи, и нагружает процессор.
В случае сбоя питания или принудительного завершения остаётся .partial.webm:
кнопка «Восстановить запись» пробует собрать из него обычный WebM, но восстановление
всего видео не гарантируется.

## Важные особенности

- Системный звук — это все звуки компьютера, даже если выбрано одно окно.
- Запись выбранного окна заканчивается, если источник перестаёт передавать видео.
- Защищённое видео и некоторые аппаратно ускоренные окна могут записываться
  чёрным экраном. В таком случае попробуйте захват всего монитора.
- Захват свёрнутого окна зависит от самой программы; оставьте его открытым.
- Частота кадров и качество зависят от мощности ПК и захватываемого приложения.
- Записи 8 Мбит/с занимают приблизительно 60 МБ в минуту плюс звук.
  Свободное место проверяется через ошибки записи; автоматического удаления нет.
- Горячие клавиши работают, пока приложение запущено. Если сочетание занято
  другой программой, Bitora ScreenFlow покажет уведомление — используйте кнопки.
- Для микрофона разрешите доступ настольным приложениям в настройках
  конфиденциальности Windows. При отказе программа покажет ошибку.
- Во время работы приложения с администраторскими правами горячие клавиши могут
  работать иначе; сама Bitora ScreenFlow не требует повышения прав.

## Исходный код

Исходники находятся в этом репозитории.
Для разработки нужен Node.js 22.12 или новее и доступ к npm:

```text
npm ci
npm start
npm test
npm run package:win
```

Сборка: Electron 45.0.0, electron-builder 26.18.0.
Команда npm run dist:win создаёт установщик и портативный EXE в release/.
Workflow Windows installer and portable собирает обе версии, проверяет запуск,
установку и удаление на Windows, после чего публикует GitHub Release.
При выпуске новой версии обновите package.json, package-lock.json и RELEASE_NOTES.md.
Запуск без Node.js обеспечивается включённым Electron.
Ключевые файлы: main.js — системные функции, трей и горячие клавиши, renderer.js — запись
и интерфейс, preload.js — ограниченный мост IPC, recording-store.js — сохранение на диск,
media-tools.js — ffmpeg (исправление, MP4, превью), settings-store.js — настройки,
shared.js — общие функции (форматирование, проверка имён, горячие клавиши, тексты ошибок).

### ffmpeg

Для MP4, исправления WebM и превью используется ffmpeg из пакета ffmpeg-static,
он входит в установщик и портативную версию (увеличивает размер примерно на 70 МБ).
При запуске из исходников можно использовать свой ffmpeg: поместите его в PATH
или задайте переменную BITORA_FFMPEG. Без ffmpeg запись и остальные функции работают,
недоступны только MP4, исправление и превью.
После добавления зависимости один раз выполните npm install, чтобы обновить package-lock.json.

### Подпись приложения

Сборки не подписаны, поэтому Windows SmartScreen может предупреждать при первом запуске.
Подпись требует сертификата подписи кода (платного) или Azure Trusted Signing.
Когда он появится, настройте подпись в electron-builder (переменные CSC_LINK и
CSC_KEY_PASSWORD в секретах GitHub) и уберите "signExecutable": false в package.json.

## Проверка этой сборки

Автоматические тесты (npm test) проверяют сохранение блоками, повторный старт,
форматирование, проверку и очистку имён файлов, горячие клавиши, тексты ошибок,
настройки и работу с ffmpeg (восстановление .partial.webm, MP4, превью).
Интерфейс версии 1.2 отрисован в Chromium с подставным API Electron.
Проверены интерфейс и медиазапись на синтетическом видеопотоке в Chromium:
выбор источника, смешивание звука, пауза и продолжение, таймер, сохранение,
переход к списку записей и обработка отказа в доступе. Полученный WebM
проверен FFprobe: видео VP9, 640×360, звуковая дорожка Opus.
Захват реального рабочего стола, системный звук, значок в трее, горячие клавиши и
сборка установщика на физическом Windows-компьютере в среде разработки не проверялись.
Перед длительной записью сделайте короткую пробу и проверьте изображение и звук.

## Скриншоты (1.3)

Выберите экран или окно и нажмите «Скриншот PNG» под предпросмотром.
Сохраняется текущий кадр полного разрешения, без звука; можно снимать и во время записи.
Снимки лежат в Screenshots внутри выбранной папки записей. После снимка открывается
предпросмотр с кнопкой «Показать в папке». Все снимки доступны через «Папка скриншотов»
в разделе «Мои записи». Если включено «Свернуть при старте», окно приложения на время
снимка скрывается, затем возвращается. Защищённый контент может быть чёрным.

## Исправление доступа (1.3.2)

Исправлена проверка внутренних запросов для путей установки с кириллицей,
апострофами, пробелами и другими символами. Сравниваются декодированные пути,
при этом запросы принимаются только от основного окна приложения.
Проверки запуска теперь обращаются к настройкам, библиотеке и источникам захвата,
а функциональный тест дополнительно запускается из папки со специальными символами.

# Bitora ScreenFlow — запись экрана

Приложение для Windows 10/11, 64 бит (x64). Интерфейс на русском языке.
Работает локально: записи не отправляются в интернет.

## Скачать и запустить

Готовые сборки: https://github.com/userArturM/bitora/releases/latest
Репозиторий приватный: для скачивания нужен доступ к нему.

**Установщик** — Bitora-ScreenFlow-Setup-1.1.0-x64.exe.
Запустите, выберите папку и завершите установку. Создаются ярлыки на рабочем
столе и в меню «Пуск». Удаление доступно через настройки приложений Windows.
Пользовательские записи при удалении сохраняются.

**Портативная версия** — Bitora-ScreenFlow-Portable-1.1.0-x64.exe.
Запускается без установки. Положите EXE в папку с правом записи. При первом
запуске рядом создаётся BitoraScreenFlow-Data с настройками и видео.
Для переноса на другой ПК копируйте EXE вместе с этой папкой.
Первый запуск может занять время: приложение распаковывается во временную папку.
Если выбрали отдельную папку видео, она остаётся внешней и автоматически не переносится.

Node.js, интернет и администраторские права для обычной работы не нужны.
Приложение не имеет цифровой подписи издателя.

Выберите источник → настройте звук → начните запись → завершите кнопкой
или Ctrl + Shift + R. Результат появится в «Мои записи».

## Возможности

- Выбор монитора или отдельного окна с миниатюрами.
- Запись системного звука, микрофона или их смеси.
- Выбор микрофона после включения доступа к нему.
- 15, 30 или 60 кадров в секунду; целевой видеобитрейт 4, 8 или 16 Мбит/с.
- Пауза и продолжение в одном видео.
- Отсчёт перед стартом и автоматическое сворачивание.
- Ctrl + Shift + R: начало / завершение; Ctrl + Shift + P: пауза / продолжение.
- Автосохранение настроек и выбор папки записей.
- Список видео, открытие во внешнем плеере, показ в проводнике и сохранение копии.
- Запись блоками на диск, без накопления всего видео в оперативной памяти.
- Предотвращение сна во время записи; сохранение перед обычным закрытием приложения.

## Куда сохраняется видео

Установленная версия: пользовательская папка «Видео» → Bitora ScreenFlow.
Портативная версия: BitoraScreenFlow-Data/Recordings рядом с EXE.
Путь отображается в «Мои записи»; его можно изменить до начала записи.
Формат: WebM (VP9 либо VP8, звук Opus).
Кнопка «Копия» сохраняет тот же формат; преобразования в MP4 здесь нет.
Для воспроизведения нужен плеер с поддержкой WebM, например VLC.
Отдельные плееры могут неточно показывать общую длительность потокового WebM.
В случае сбоя питания или принудительного завершения остаётся .partial.webm:
его можно попробовать открыть, но восстановление всего видео не гарантируется.

## Важные особенности

- Системный звук — это все звуки компьютера, даже если выбрано одно окно.
- Запись выбранного окна заканчивается, если источник перестаёт передавать видео.
- Защищённое видео и некоторые аппаратно ускоренные окна могут записываться
  чёрным экраном. В таком случае попробуйте захват всего монитора.
- Захват свёрнутого окна зависит от самой программы; оставьте его открытым.
- Частота кадров и качество зависят от мощности ПК и захватываемого приложения.
- Записи 8 Мбит/с занимают приблизительно 60 МБ в минуту плюс звук.
  Свободное место проверяется через ошибки записи; автоматического удаления нет.
- Горячие клавиши работают, пока приложение запущено. Если сочетание занято
  другой программой, Bitora ScreenFlow покажет уведомление — используйте кнопки.
- Для микрофона разрешите доступ настольным приложениям в настройках
  конфиденциальности Windows. При отказе программа покажет ошибку.
- Во время работы приложения с администраторскими правами горячие клавиши могут
  работать иначе; сама Bitora ScreenFlow не требует повышения прав.

## Исходный код

Исходники находятся в этом репозитории.
Для разработки нужен Node.js 22.12 или новее и доступ к npm:

```text
npm ci
npm start
npm test
npm run package:win
```

Сборка: Electron 45.0.0, electron-builder 26.18.0.
Команда npm run dist:win создаёт установщик и портативный EXE в release/.
Workflow Windows installer and portable собирает обе версии, проверяет запуск,
установку и удаление на Windows, после чего публикует GitHub Release.
При выпуске новой версии обновите package.json, package-lock.json и RELEASE_NOTES.md.
Запуск без Node.js обеспечивается включённым Electron.
Ключевые файлы: main.js — системные функции, renderer.js — запись и интерфейс,
preload.js — ограниченный мост IPC, recording-store.js — сохранение на диск.

## Проверка этой сборки

Проверены синтаксис JavaScript, последовательная запись данных и переименование
файла после окончания, удаление пустого файла, повторный старт.
Проверены интерфейс и медиазапись на синтетическом видеопотоке в Chromium:
выбор источника, смешивание звука, пауза и продолжение, таймер, сохранение,
переход к списку записей и обработка отказа в доступе. Полученный WebM
проверен FFprobe: видео VP9, 640×360, звуковая дорожка Opus.
Захват реального рабочего стола, системный звук и горячие клавиши на физическом
Windows-компьютере в среде разработки не проверялись.
Перед длительной записью сделайте короткую пробу и проверьте изображение и звук.

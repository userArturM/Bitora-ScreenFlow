## Bitora ScreenFlow 1.1.0

Приложение для записи экрана на Windows 10/11 x64.

- **Setup.exe** — установщик с выбором папки, ярлыками и удалением через Windows.
- **Portable.exe** — запуск без установки. Настройки и видео по умолчанию хранятся
  в папке BitoraScreenFlow-Data рядом с EXE. Переносите эту папку вместе с программой.

Запись монитора или окна, системного звука и микрофона; пауза, отсчёт,
горячие клавиши, настройки качества, библиотека записей. Формат видео: WebM.

Установщик автономный: интернет для установки и записи не требуется.
Сборки не подписаны сертификатом издателя. Автоматические проверки запуска,
установки и удаления не заменяют проверку захвата экрана и звука на вашем ПК.

Горячие клавиши: Ctrl+Shift+R — начало/конец, Ctrl+Shift+P — пауза.
Контрольные суммы файлов опубликованы в SHA256SUMS.txt.

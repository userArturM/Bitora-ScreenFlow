# Bitora ScreenFlow 1.5.0 — Dark Lime

Новый тёмный интерфейс с лаймовыми акцентами по выбранному макету: большой предпросмотр, компактная правая панель, таймер и кнопка записи. Дополнительные параметры вынесены в «Настройки». Добавлено разворачивание предпросмотра.

Все функции студии сохранены. Перед обновлением закройте приложение через трей → Выход.

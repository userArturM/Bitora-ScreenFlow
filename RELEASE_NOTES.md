# Bitora ScreenFlow 1.6.0

- Исправлена перемотка и полноэкранный просмотр. Добавлены скорость, кнопка полного экрана, горячие клавиши и ползунки выбора фрагмента.
- Обновления скачиваются внутри приложения с проверкой размера и SHA-256. Скачивание можно отменить и продолжить, в том числе после перезапуска.
- Установка ждёт завершения операций; portable обновляется с резервной копией и автоматическим возвратом при ошибке запуска.
- Результат установки записывается в отчёт; ошибка показывается при следующем запуске.
- Незавершённые записи предлагаются к восстановлению при запуске. Сохранение синхронизируется с диском каждые пять секунд; ошибки записи сохраняют файл .partial.webm.
- При потере аудиодорожки запись останавливается с сохранением полученных данных.

## Как обновиться с 1.5.1

В 1.5.1 ещё нет нового механизма обновлений, поэтому первый переход выполняется вручную.

Установленная версия: завершите запись, закройте программу и запустите Bitora-ScreenFlow-Setup-1.6.0-x64.exe. Используйте прежнюю папку установки. Записи и настройки не удаляются.

Portable: завершите операции и закройте программу. Сохраните прежний EXE как резервную копию, поместите новый Portable EXE рядом с папкой BitoraScreenFlow-Data. Не удаляйте эту папку — она содержит настройки и записи.

Следующие версии: «Обновления» → «Скачать обновление» → «Установить после завершения операций». При обрыве нажмите «Продолжить скачивание». Для отмены ожидания установки используйте кнопку отмены.

Проверки и оставшиеся ограничения описаны в QA.md.

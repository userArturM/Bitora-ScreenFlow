## Bitora ScreenFlow 1.2.0

Приложение для записи экрана на Windows 10/11 x64.

- **Setup.exe** — установщик с выбором папки, ярлыками и удалением через Windows.
- **Portable.exe** — запуск без установки. Настройки и видео по умолчанию хранятся
  в папке BitoraScreenFlow-Data рядом с EXE. Переносите эту папку вместе с программой.

### Новое в 1.2

- Сохранение записей в MP4 одной кнопкой.
- Автоматическое исправление длительности и перемотки WebM, восстановление .partial.webm.
- Значок в трее: время записи, пауза и завершение без открытия окна.
- Настраиваемые горячие клавиши (по умолчанию Ctrl+Shift+R и Ctrl+Shift+P).
- Библиотека: превью, длительность, переименование, удаление в корзину.
- Индикатор уровня звука, свободное место на диске, остановка при нехватке места.
- Крупнее и контрастнее текст, понятные сообщения об ошибках на русском, иконки вместо символов.
- Установщик стал больше: в него входит ffmpeg.

Горячие клавиши по умолчанию: Ctrl+Shift+R — начало/конец, Ctrl+Shift+P — пауза.
Сборки не подписаны сертификатом издателя, Windows может показать предупреждение SmartScreen.
Автоматические проверки запуска, установки и удаления не заменяют проверку захвата
экрана и звука на вашем ПК. Контрольные суммы файлов опубликованы в SHA256SUMS.txt.

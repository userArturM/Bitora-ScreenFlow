# Bitora ScreenFlow 1.6.0-rc.1 — предварительный релиз

**Известное ограничение: автоматическая установка обновлений отключена.** Windows-тест помощника установки не проходит. Используйте ручную установку EXE; этот выпуск не является стабильным 1.6.0. Проверка полного обновления/отката для отключённой функции исключена из условий публикации RC, остальные проверки сборки, записи и проигрывателя остаются обязательными.

Доступны исправления перемотки и fullscreen, скорость и горячие клавиши проигрывателя, выбор фрагмента, восстановление незавершённых записей, скачивание с проверкой SHA-256 и продолжение загрузок. Автоматический откат portable также не заявляется рабочим в этом выпуске.

## Ручная установка
Завершите запись и закройте приложение. Для установленной версии запустите Setup EXE и выберите прежнюю папку. Для portable сохраните старый EXE, замените его новым рядом с существующей BitoraScreenFlow-Data. Эту папку не удаляйте.

## Проверки
Обязательные проверки: модульные тесты, запуск установщика и portable, запись видео со звуком в CI, PNG, перемотка, fullscreen и масштабы 125/150/200%. Ограничения аппаратных проверок — в QA.md.

# Bitora ScreenFlow 1.5.1 — монограмма SF

Новая переплетённая монограмма SF в стиле Dark Lime: интерфейс, окно, трей, EXE, установщик и ярлыки. Иконка Windows содержит размеры от 16 до 256 пикселей.

Все функции версии 1.5 сохранены. Перед обновлением закройте приложение через трей → Выход. Сборки не подписаны сертификатом издателя.

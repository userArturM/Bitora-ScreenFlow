# Bitora ScreenFlow 1.4.1

Новый логотип с лаймовым кольцом: интерфейс, окно приложения, трей, EXE, ярлыки и установщик. Использовано предоставленное изображение с сохранением прозрачности. Значок Windows содержит размеры от 16 до 256 px.

Перед обновлением закройте старую версию через трей → Выход. Настройки и записи удалять не нужно.

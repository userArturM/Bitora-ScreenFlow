# Bitora ScreenFlow 1.4.0

Область записи с точными размерами и запоминанием; редактор PNG; плавающая панель; единая библиотека с поиском и проигрывателем; отдельные уровни звука и тест микрофона; обрезка видео в MP4; проверка обновлений; локальный диагностический отчёт.

Обновления приватного репозитория загружаются через авторизованный браузер GitHub. Автоустановка не выполняется. На старых Windows защищённая панель может отображаться в записи чёрным прямоугольником — её можно отключить.

Перед обновлением закройте старую версию через трей → Выход. Записи и настройки удалять не нужно.

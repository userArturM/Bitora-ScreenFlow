# Bitora ScreenFlow 1.6.0

- Исправлены перемотка видео и полноэкранный режим встроенного проигрывателя.
- Добавлены скорость воспроизведения, горячие клавиши и выбор границ фрагмента.
- Исправлена проверка доступа для путей с кириллицей, пробелами, апострофами, # и %.
- Добавлено восстановление незавершённых записей; при ошибке записи сохранённая часть остаётся доступна для восстановления.
- Обновления скачиваются внутри приложения с проверкой SHA-256 и продолжением прерванной загрузки.
- Установка ожидает завершения записи и других операций. Независимый Windows-помощник повторно проверяет SHA-256, устанавливает обновление и проверяет запуск приложения.
- Для portable сохраняется предыдущий EXE; при неудачной проверке запуска выполняется автоматический откат.

## Установка
Для перехода с 1.5.1 или 1.6.0-rc.1 завершите запись, закройте приложение и запустите новый Setup. Для portable замените EXE, сохранив папку BitoraScreenFlow-Data.

## Проверки и ограничения
Перед публикацией обязательны модульные тесты, Windows-проверки записи и проигрывателя, запуск обеих сборок и реальный цикл обновления 1.5.1 → 1.6.0. Подробности и границы аппаратных проверок описаны в QA.md. Автоматический откат установленной версии не предусмотрен; при ошибке установки доступен отчёт и ручная переустановка. EXE без цифровой подписи издателя.

# Проверки ScreenFlow 1.6.0

Автоматическая проверка перед публикацией:
- Модульные проверки, повреждённые загрузки, отмена/продолжение после нового экземпляра приложения, очередь установки.
- Принудительное завершение процесса записи и восстановление сохранённого WebM через FFmpeg; имитация ENOSPC.
- Реальная запись экрана CI со звуковой дорожкой от синтетического микрофона, пауза/продолжение, PNG, FFmpeg-декодирование, проигрыватель, перемотка и fullscreen.
- Скорость воспроизведения, выбор границ фрагмента, событие отключения аудиодорожки.
- Запись по 60 секунд с масштабами Chromium 125%, 150% и 200%.
- Установщик и portable 1.5.1 → 1.6.0: HTTP Range загрузка реальных EXE через локальный сервер вместо ещё не опубликованного релиза GitHub, SHA-256, реальная установка и запуск. Отдельный отказ запуска и откат portable.

Это не заменяет аппаратную проверку. Остаются ручные проверки на компьютере с двумя физическими мониторами (разные DPI и отрицательные координаты), реальным USB/Bluetooth-микрофоном и системным звуком, сменой устройства вывода и записью 1–2 часа. Масштаб Chromium на CI не равнозначен переключению системного DPI Windows. Событие отключения аудиодорожки моделируется; физическое извлечение USB в CI не выполняется.

Проверка реального отключения питания также не выполняется: тест убивает процесс. Синхронизация каждые пять секунд уменьшает возможную потерю, но не гарантирует сохранность при сбое накопителя/питания. Невосстановимый исходный файл остаётся на диске.

Установка версии 1.5.1 не содержит новый updater, поэтому интеграционный тест использует новый модуль загрузки/установки для перехода между настоящими сборками. Последовательность UI и ожидание операций покрываются отдельными проверками.
